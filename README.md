# WinFormCalculadora

Uma calculadora de desktop desenvolvida em **C# utilizando Windows Forms**.

## Sobre o projeto

O WinFormCalculadora é um projeto desenvolvido para praticar conceitos de desenvolvimento de aplicações desktop com C# e Windows Forms.

A aplicação possui uma interface gráfica simples e permite realizar operações matemáticas básicas diretamente pela calculadora.

## Funcionalidades

* ➕ Adição
* ➖ Subtração
* ✖️ Multiplicação
* ➗ Divisão
* 🧹 Limpeza da expressão
* ⚠️ Identificação de erros de sintaxe
* 🖥️ Interface gráfica desenvolvida com Windows Forms

## Tecnologias utilizadas

* **C#**
* **.NET Framework 4.7.2**
* **Windows Forms**
* **Visual Studio**

## Como executar

### Pré-requisitos

Para executar o projeto, é necessário possuir:

* Windows
* Visual Studio com suporte a desenvolvimento para desktop com .NET Framework

### Execução

1. Clone este repositório.
2. Abra o arquivo `WinFormCalculadora.sln` no Visual Studio.
3. Compile o projeto.
4. Execute a aplicação.
